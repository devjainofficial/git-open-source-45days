# Contributing Guide

Thanks for helping improve this learning repo!

## Ways to Contribute
- Fix typos, improve explanations, add examples
- Add practice scenarios or tests for a day
- Suggest new topics for Days 31–45 via Issues
- Review PRs and give constructive feedback

## Workflow
1. Fork the repo and clone your fork.
2. Create a feature branch: `git checkout -b improve/day-XX-<short-title>`
3. Make changes inside `days/dayXX/` or docs.
4. Commit with a clear, conventional message (see Day 4).  
5. Push and open a Pull Request with context and screenshots if relevant.

## Commit Message Hints
- Prefix with `feat`, `fix`, `docs`, `refactor`, `chore` where possible
- Keep the subject ≤ 72 chars; put details in the body

## Code of Conduct
By contributing, you agree to our [Code of Conduct](CODE_OF_CONDUCT.md).
