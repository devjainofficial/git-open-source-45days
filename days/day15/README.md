# Day 15: Stash

**Summary:** Save work-in-progress and return later without committing.

## Key Commands
```bash
git stash push -m "WIP: form validation"
git stash list
git stash pop
```

## Practice Scenario
Stash changes, switch branches, return and pop; note any conflicts.

## Pro Tips
- Name your stashes; avoid long-lived stashes to prevent surprises.
