# Day 07: Branching Fundamentals

**Summary:** Create, switch, and delete branches. Understand safe cleanup after merge.

## Key Commands
```bash
git switch -c feature/login
git switch main
git branch -d feature/login
```

## Practice Scenario
Create 2 branches, merge one, then safely delete it.

## Pro Tips
- Delete merged branches to reduce clutter; keep long-lived branches only if needed.

> **Note:** Recover deleted branches via reflog if needed.
