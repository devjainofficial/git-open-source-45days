# Day 09: Forking vs Cloning

**Summary:** Fork to contribute to someone else’s project; clone to get a local copy.

## Key Commands
```bash
# on GitHub: Fork; then locally:
git clone <your-fork-url>
git remote add upstream <source-repo-url>
```

## Practice Scenario
Fork a popular repo, clone your fork, add `upstream`, and fetch.

## Pro Tips
- Keep your fork up-to-date via `git fetch upstream` + `git merge` or `git rebase`.
