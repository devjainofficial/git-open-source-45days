# Day 12: git pull vs git fetch

**Summary:** Understand that `pull = fetch + merge` (or rebase). Choose intentionally.

## Key Commands
```bash
git fetch
git pull --rebase
```

## Practice Scenario
Simulate remote updates, try `fetch` then examine, then `pull` to integrate.

## Pro Tips
- Default pull strategy can be set: `git config pull.rebase true`.
