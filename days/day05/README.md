# Day 05: Remotes: origin & upstream

**Summary:** Connect your local repo to a remote, and understand `origin` vs `upstream` naming conventions.

## Key Commands
```bash
git remote add origin <your-fork-url>
git remote add upstream <source-repo-url>
git remote -v
```

## Practice Scenario
Add both `origin` and `upstream` to a test repo. Fetch from both.

## Pro Tips
- Default branch names vary (`main` is common). Be inclusive in naming.

> **Note:** You pull from `upstream`, push to your `origin` (fork).
