# Day 08: Switch vs Checkout

**Summary:** Use `git switch` for branches and `git restore` for files for clarity.

## Key Commands
```bash
git switch -c ui/header
git restore --staged file.txt
```

## Practice Scenario
Migrate your workflow from `checkout` to `switch/restore`.

## Pro Tips
- `switch`/`restore` are safer, more explicit than `checkout`.
