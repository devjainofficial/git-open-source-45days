# Day 06: Clone (full vs shallow)

**Summary:** Clone repos and use shallow clones for speed when history isn't needed.

## Key Commands
```bash
git clone <url>
git clone --depth 1 <url>
```

## Practice Scenario
Clone a large repo shallowly; compare size and history depth.

## Pro Tips
- Use shallow clone for CI to save time; avoid for deep history tasks.
