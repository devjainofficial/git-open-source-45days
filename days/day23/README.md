# Day 23: Submodules

**Summary:** Include another repo inside your repo while keeping histories separate.

## Key Commands
```bash
git submodule add <url> path/
git submodule update --init --recursive
```

## Practice Scenario
Add a toy submodule; update and pin to a specific commit.

## Pro Tips
- Pin to commits; prefer subtrees/monorepos for fast-moving internal code.
