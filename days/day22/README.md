# Day 22: Worktree

**Summary:** Check out multiple branches simultaneously in separate directories.

## Key Commands
```bash
git worktree add ../hotfix-001 hotfix/001
git worktree remove ../hotfix-001
```

## Practice Scenario
Add a worktree for a hotfix while your main work remains open.

## Pro Tips
- Name worktree dirs clearly; remove stale ones.
