# 45-Day Git & Open Source Journey

_Fork this repo, follow one day at a time, and become contribution‑ready._

## 🌟 How to Use This Repo
1. **Fork** this repository (or click **Use this template**).
2. **Clone** your fork locally.
3. Create a practice branch for the day: `git checkout -b practice/day-XX`.
4. Open `days/dayXX/README.md` → read & do the **Practice Scenario**.
5. Commit using meaningful messages and **push** to your fork.
6. (Optional) Open a **Pull Request** from your fork to this repo for feedback.
7. Repeat tomorrow. Small steps → big progress.

> Tip: Try this entirely in the browser with **GitHub Codespaces**.

## 📚 What You'll Learn (Days 1–45)
- ✅ Day 01–15: Foundations — install, init, commits, branches, remotes, forks, PRs, fetch vs pull, reset vs revert, stash
- ✅ Day 16–23: Advanced — cherry-pick, clean, bisect, reflog, rebase (basic & interactive), worktree, submodules
- 🔜 Day 24–30: Hooks, Internals, Tagging, Remotes deep-dive, Licenses, Community files, Issues/Discussions
- 🔜 Day 31–45: GitHub collaboration, reviews, releases, CI, automation, capstone
